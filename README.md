# Nancy — Portfolio

A responsive, static portfolio built with React, TypeScript, and Vite. Experience includes the CRIS internship, TI Infotech internship, Ikigai Lab Data Science and Machine Learning training, and Infosys Springboard Pragati Path. The Achievements section links to Nancy's supplied credentials; the Ikigai training entry links directly to its certificate.

## Run locally

```sh
npm install
npm run dev
```

## Validate

```sh
npm test
npm run build
```

The supplied certificate files remain in `public/certificates/`; there is no certificate gallery on the page. A locally stored workspace photo provides a continuous, full-page background and a focal image in the hero. The header includes a light/dark theme toggle. The contact section has a form that prepares an email in the visitor’s default mail app; it does not send or store form data. LinkedIn and GitHub are presented as labeled buttons. Scroll progress and section navigation indicate your position on the page.
